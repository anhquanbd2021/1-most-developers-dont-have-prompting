Route it before you write it

The five surfaces differ on two axes — when the instruction loads and whether anything enforces it. The routing decision matches an instruction's properties to both.

The precedence order

Ask the questions enforcement-first. Asking "always true?" first misroutes enforceable rules into CLAUDE.md — the classic enforcement gap.

  1. Must it happen every time? → hook. Only hooks run code; everything else is text the model reads and mostly follows.
  2. Does it need its own context? → subagent. Delegation is structural: different context, different tools.
  3. Is it a repeatable procedure? → skill. Loaded on demand, absent the rest of the time.
  4. Does it apply only to some files? → scoped rule with a path glob. Conditional context.
  5. Is it true of every task? → CLAUDE.md. Always-on project facts — and nothing else.
  6. None of the above? → the prompt. Not everything belongs in the control plane.

The failure catalog

  • enforcement-gap — must-enforce rule on an advisory surface: read every turn, guaranteed never.
  • over-enforcement — advisory text on a hook: a deterministic slot spent on a rule that needs judgment, or context tax rewritten as code.
  • context-tax — scoped or procedural text in CLAUDE.md: paid every turn, relevant occasionally.
  • coverage-gap — always-true fact in a scoped rule or skill: correct where it applies, absent everywhere else.
  • context-pollution — delegated work inlined into the main context: the writer grading its own homework.

Honest limits

  • Compliance on advisory surfaces is simulated at 92% — a documented constant, not a measurement. The lab reproduces the shape of each failure, not your model's exact rates.
  • Hooks enforce only checkable rules at defined events; real hook APIs differ per tool (PreToolUse/PostToolUse matchers, exit codes).
  • Real surfaces have more knobs: skill triggers, agent tool sets, settings precedence. The lab teaches the routing decision, not any tool's exact file layout.
  • Scoped-rule and skill loads assume the match/invocation lands exactly when relevant — real globs and triggers have false positives and misses.
